# ⚖️ José Ignacio Pino Diaz — Sitio Web Profesional & Asesoría Jurídica

Sitio web corporativo tipo *landing page* desarrollado para el profesional del derecho **José Ignacio Pino Diaz** (Egresado en Derecho, UCSC). La plataforma está enfocada en ofrecer una presentación elegante de sus servicios, materias de práctica (Derecho de Familia, Civil y Penal) y canales directos de contacto para clientes.

## 🚀 Características Principales

* **Diseño Ejecutivo "Navy & Gold":** Estética moderna con contraste en azul marino oscuro y detalles en dorado.
* **Integración con EmailJS:** Formulario de reserva de consultas que envía los datos del cliente directamente al correo institucional.
* **Modal de Confirmación Interactivo:** Confirmación emergente con efecto de fondo borroso (`backdrop-blur`) tras enviar una consulta.
* **Atención Inmediata vía WhatsApp:** Botón flotante responsivo y enlaces directos para iniciar conversación rápida.
* **Menú Móvil Animado:** Navegación fluida tipo *slide & fade* optimizada para smartphones y tablets.
* **Modales de Áreas de Práctica:** Detalle descriptivo interactivo para materias de Familia, Civil y Penal.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica y accesible.
* **Tailwind CSS (CDN):** Estilizado reactivo y utilidades de diseño responsivo.
* **JavaScript (ES6+):** Lógica del sitio, control de modales y gestión del envío de formularios.
* **EmailJS SDK:** Servicio de envío de correo en cliente sin backend propio.
* **Font Awesome 6:** Iconografía jurídica y de contacto.
